# 参考图编辑诊断（2026-10-18）

本次蓝色陶瓷杯案例的可复现触发条件是：编辑沿用了生成参考图的 Seed 42。相同的参考图、编码结果、尺寸、采样器与步数，仅将编辑 Seed 换成 314159，就恢复了桌布与书本的编辑，明显过锐化消失。原编码器与 GGUF 编码器都验证了这一点，不能将这次故障归因于新编码器。

## 对照设置与结果

原图是 Seed 42 生成的 1024 × 1024 蓝杯木桌静物。编辑指令：

> Keep the blue ceramic cup from image 1. Place it on a pale linen tablecloth beside a closed green book, soft daylight, still life photograph.

标准版 Qwen-Image 2.1 INT8 主模型、原 BF16 VAE、Euler/simple、25 步、CFG 1。参考图同时接入视觉编码与 VAE 条件。为避免本机内存不足，后续对照将编码结果保存后在新进程中采样，保存的条件包含完整参考图潜变量及插入位置。

| 对照 | 结果 |
| --- | --- |
| GGUF 编码器、编辑 Seed 42 | 木桌未替换、书本缺失、明显过锐 |
| 原编码器、编辑 Seed 42 | 同样失败 |
| GGUF、40 步 / CFG 3，仍为 Seed 42 | 未改善 |
| 关闭参考条件缓存，仍为 Seed 42 | 未改善 |
| 原编码器、改成更明确的替换指令，仍为 Seed 42 | 未改善 |
| 原生归一化与位置编码计算替代融合算子 | 未改善，已恢复 |
| 保留权重量化、取消 INT8 激活矩阵计算 | 未改善，已恢复 |

| 当前 GGUF 编码器、编辑 Seed 314159 | 杯子特征保留、浅色亚麻桌布与一本合上的绿书出现，柔和日光，无明显过锐 |

## Studio 处理

- 随机 Seed 避开当前所有站内生成参考图的已知 Seed。
- 手动 Seed 若与这些参考图冲突，在入队前返回 `REFERENCE_SEED_CONFLICT`，提示清空或更换数值；不静默修改用户指定值。
- 前端在使用参考图时说明 Seed 建议留空。
- 不改动已冻结任务及按原参数重试；修正质量问题应新建任务并换 Seed。
- 导入图片当前不保留生成 Seed 元数据，无法自动识别其种子；上传图片的占位值 0 不视为已知生成种子。
