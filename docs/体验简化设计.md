# 同框体验简化（2026-10-18）

目标：第一次只需介绍自己并点击开始；后续专注聊天，点击“生成这一刻”自动读取剧情。用户无需理解人设快照、参考编号和画面结构。

## 本轮交付

- 首次入口“让故事里的我入镜”，仅展示称呼与简单介绍；外貌和初始服装折叠。点击“以这个身份开始”在一个事务中创建资料、绑定聊天、保存偏好。
- 已有身份默认只显示姓名、镜头与“修改资料”。镜头选择即保存，不再要求额外点击保存。
- 修改资料离开输入框即保存；参考上传或取消选用后自动保存。保存中与失败状态明确显示，失败保留输入，提供重试和重新载入。版本冲突不覆盖其他修改。
- 同一身份的资料修正影响当前聊天和后续新聊天，不回写其他已有聊天。旧图片任务继续使用其冻结资料。
- 新聊天沿用最近使用的身份和镜头，开场白的用户名字采用该身份。已有未绑定聊天不自动改变。
- 可以显式选择“从现在起使用这个身份”，在当前聊天切换后续身份；不改写历史文本和图片。
- 画面摘要收拢为入镜人物、场景、互动的一段描述；完整字段放在“修改画面”内。仍支持生成时自动读取剧情。

## 验收与边界

全量 62 项测试通过；最终补充身份切换后再次运行人设回归与类型检查、构建。浏览器使用独立测试库验证自动保存反馈，不写入用户真实聊天。

自然语言纠错、只改本张/沿用后续的作用范围、关键歧义询问作为下一阶段；本轮不把补充要求冒充为结构化纠错。资料仍采用明确字段，简单介绍不自动猜测外貌。

自动保存采用失焦触发，不承诺尚未离开输入框时强制关闭页面也能保存。参考图需完成首次身份创建后再添加，但不需要第二次手动保存或绑定。

本设计覆盖《双人同框设计》中旧版“资料库修改不更新当前聊天、换身份必须新建聊天”的交互限制；历史任务快照保护保持有效。

## 第二轮：一句话修正画面

已实现入口“ 一句话修改 ”：输入修改 → “理解这句话” → 查看字段变化 → “仅这张”或“后续沿用”。没有画面状态时先自动读取聊天。模型只收到当前画面与本次要求，不带完整聊天、人设描述或私有聊天预设。它输出最小字段补丁；服务端拒绝身份/姓名/人数字段、未知人物、重复字段、超长或无效输出。

“仅这张”保留在当前界面的临时状态，只随下一次成功入队的任务冻结，成功后清除，失败可重试；不会写入聊天。切换聊天、来源消息或画面上下文变化也会丢弃临时状态。可以主动撤销。

“后续沿用”使用既有画面检查点保存机制，仅修改本聊天的画面状态，不改人设库、聊天文本或旧任务。新的明确剧情仍可覆盖该状态；不是永久锁定服装。

模型不确定指代时显示一个澄清问题，不应用变化。用户在同一输入框补充明确人物后再次理解。出镜模式仍使用镜头选择，不通过补丁隐式改变。

验证：最新全量 64 项测试、类型检查、构建通过。隔离浏览器使用本地模拟文本接口验证了差异预览、仅本张成功入队后清除、原保存状态不变、歧义提示、澄清后持久应用。使用虚构书店人物，隔离 worker 关闭，没有提交真实生图。尚未系统性验证真实文本模型对自然语言修正的准确率；展示差异供用户检查是当前必要边界。
