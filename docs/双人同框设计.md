# 当前角色与用户人物同框

## 第一版范围

目标是角色 main 与用户扮演的人物 user 同框，自动从聊天更新双方服装、表情和动作。沿用现有多人 SceneState，不另建一套生成管线。

1. 新增独立用户人设库：姓名、人物描述、稳定外貌、默认服装、面部/全身参考，带版本号。参考图所有权属于人设，不能冒用角色或另一个人设的素材。
2. 聊天首次绑定人设时复制完整快照。人设库后续编辑不影响已绑定聊天；第一版不允许在已绑定聊天中换成另一身份，换身份请新建聊天。已有未绑定聊天可主动绑定，未绑定时完全保留原行为。
3. 每段聊天保存镜头模式 auto（默认自动）、together（双人同框）、pov（用户视角）。双人及用户视角模式要求先绑定人设。更改模式使旧画面预览失效，已有图片任务不变。
4. 解析时 assistant 对应 main，user 消息对应 user；引语、回忆、假设不能直接变成当前动作。两个固定编号不因左右位置改变。必须返回双方，缺少 user 的模型结果拒绝保存，避免静默丢失人物。
5. 稳定外貌由各自资料提供；服装、穿着状态、表情、动作各自继承。主角参考不再套给所有人物。参考列表带 personId，实际 imageN 顺序与送入模型的顺序一致；不入镜的人物不上传参考。服装变化后不继续使用旧服装参考。
6. 双人模式明确双方入镜；用户视角让用户完整身体在画外，第一版保守不自动生成人物局部肢体，避免与既有画外约束矛盾。自动模式由剧情判断，不因仅提到一个人就强行同框。
7. 普通聊天的用户资料和 {{user}} / personaDescription 使用聊天快照；原私有预设 JSON 不改写。预设未启用 personaDescription 时仍保留独立的用户身份素材。
8. UI 在生图侧栏提供“我的人设与同框”，支持创建、编辑库资料、上传参考、绑定聊天及选择镜头。画面摘要分别展示双方状态。

## 数据与兼容

增加 personas 表，原表与数据不删除。Chat 增加可选 userPersona、framing；VisualSnapshot 增加可选 userPersona、framing，参考条目的 personId 缺省 main。旧聊天、旧图、旧任务快照无需迁移。任务提交冻结完整资料和参考排序，重试不重编译新资料。

用户人设变化或镜头变化纳入 visualContextKey；正在推断时资料改变需拒绝旧结果。保存接口校验 revision，绑定和模式变更在文本推断/聊天生成期间拒绝。所有上传继续走 PNG 清理与大小限制。

## 验证

- 测试人设持久化、版本冲突、跨人设参考拒绝、聊天快照隔离、旧行为兼容。
- 测试双方服装不串、固定身份缺失拒绝、同框/用户视角、参考编号与冻结工作流一致。
- 测试普通预设和完整预设使用用户名字，原 JSON 不变。
- 全量回归、类型检查、构建及界面验证；真实生图仅使用虚构成年人物和中性场景。画面质量与代码正确性分别验收，不能把接口通过当作身份一致性已解决。

暂不加入区域遮罩、姿态控制或局部重绘。两张参考同时输入并不保证身份绑定，先记录真实出图效果，再决定是否需要第二阶段分区域修正。

## 第一版交付与实测（2026-10-18）

上述接口、持久化、提示词编排、参考图分配与界面已实现。绑定人设后，预览及任务提交必须有双方画面状态，不能绕过人数与参考过滤。

- 全量 61 项测试通过；最终增加无画面状态的防绕过校验后，12 项相关回归及类型检查再次通过。前端构建通过。
- 独立 3001 测试数据完成创建“林舟”、保存、绑定双人同框、切换用户视角的浏览器检查。未向生产聊天写入测试人设。
- 真实本地模型：分别生成成年红发女性蓝裙、成年黑发男性白衬衫参考图，再通过正式 compileVisualPrompt 与 sceneVisual 编排进行双参考生成。两张来源图耗时 22.2 秒、20.2 秒，双人图耗时 48.5 秒，均完成且未重启 ComfyUI。
- 双人图保留了双方可辨识的面部特征和各自服装，左右站位正确，共同持有绿色书。局限：两人仍明显朝向镜头，呈现摆拍感，尚不足以证明自然递书动态及任意复杂互动可靠。
- 本地实验记录：`temp/persona-render/{main,user,together}.json`，图像同名 `.png`。实验脚本 `temp/persona-render.mjs`。仅虚构人物，不含真实聊天或私有预设；未发送外部文本接口。
- 已在空闲时备份数据库并更新 Tavern，ComfyUI 未重启。更新前后角色、聊天、消息、设置、原始预设五项哈希一致；原 3 个角色、5 段聊天、259 条消息和 47 个图片任务保留。

使用路径：打开聊天 → 右侧“我的人设与同框” → 保存人设 → 可选上传参考并再次保存 → 选择“双人同框” → 绑定到本聊天。之后读取聊天或直接点击生成即可按双方状态编排。库资料修改不回写已绑定快照，首次绑定前应确认资料和参考。旧开场白也不会追溯改写。
