# 共叙 · Tavern Studio

基于酒馆使用体验开发的本地优先角色聊天与图像创作应用。当前版本 **0.1.0 / 首个可运行迭代**，不是完整酒馆替代品。

## 已实现

- Vue 3 + TypeScript 前端：角色库、聊天工作台、图库、任务中心、模型设置与窄屏抽屉。
- Fastify + TypeScript 后端、原生 Node SQLite 持久化、同源 SSE 事件。
- 角色新建、带 revision 的编辑、基础 JSON / V2 PNG 卡片导入及 JSON 导出；保留未知卡片字段。
- 三个本地示例角色与开场白；不会伪造模型生成的回复。
- 显式配置的 Chat Completions 兼容文本接口：SSE 回复、停止、部分文本保存、重启后的中断恢复。
- 自动读取聊天并维护画面状态，支持手动编辑服装、动作与表情，生成和预览实际生图提示词；选中消息时不使用后续剧情。首次状态推断目前按批次读取历史，长篇对话可能较慢。
- 复用现有 Qwen-Image-2.1 标准工作流：1024×1024、25 步、CFG 1、Euler / simple、batch 1。
- 图片任务持久化、幂等创建、单任务调度、采样进度、连接核对、取消、离线停止追踪与按原参数重试。
- 工作流参数快照、媒体归档、默认剥离 PNG 元数据、消息关联与图片下载。
- 角色定稿：固定身份、默认服装、面部/全身/服装 PNG 参考图；可从本角色图库选择参考。
- 会话换装：用户确认并指定生效消息，历史绘图使用当时的服装；任务冻结参考图、服装版本与最终提示词。
- Loopback 监听、Host / Origin 检查、HttpOnly 本地会话与 CSRF 防护；不自动启动或下载模型。

## 快速启动

全新克隆需要自行安装 Node.js 24+，然后在仓库根目录执行：

```sh
npm ci
npm run build
npm start
```

打开 `http://127.0.0.1:3000`。文本模型和 ComfyUI 是独立服务，需要自行安装、启动并在设置中配置。仓库不包含模型权重、API 密钥、聊天记录、个人角色卡或生成图片。

当前默认工作流包含实验性 GGUF 编码器节点，请先阅读 [接入说明](integrations/comfyui-gguf/README.md)。参考图编辑质量与 Windows 内存访问崩溃仍在排查，不能视为已解决。使用原编码器可按接入说明回退。

### 直接使用

双击 `Start.cmd`，或在本目录执行：

```powershell
.\Start.ps1
```

访问 `http://127.0.0.1:3000`。终端中按 Ctrl+C 停止。默认使用已有的 `../runtime/node-v24.19.0-win-x64`，不改动系统 Node 环境。

### 开发模式

```powershell
.\Start-Dev.ps1
```

前端 `http://127.0.0.1:5173`，后端 `http://127.0.0.1:3000`。Vite 同源代理 `/api`，后端与前端均支持开发重载。不要同时启动生产后端和开发后端：同一个数据库只允许一个后端实例持有。

### 重新构建与测试

```powershell
.\Build.ps1
..\runtime\node-v24.19.0-win-x64\node.exe --test apps/server/tests/studio.test.ts
```

若已经把 Node 24+ 加入 PATH，也可使用 `npm run dev`、`npm run build`、`npm test`。依赖由根目录 `package-lock.json` 锁定；全新工作副本安装使用 `npm ci`，需要访问 npm registry。

测试使用独立临时数据库及本机模拟文本 / ComfyUI 服务，不下载权重、不占用 GPU、不改动实际模型配置。真实模型的画质、速度和显存尚需单独验收。

## 连接文本模型

打开“模型与设置”：

1. 输入基础地址，例如 `http://127.0.0.1:1234/v1`；不要追加 `/chat/completions`。
2. 填写接口实际支持的模型 ID，必要时输入密钥。
3. 点击“保存并测试连接”，成功后可从发现的模型列表选择名称。
4. 回到角色库开启会话。

首版要求服务支持标准 SSE 文本增量；不是所有宣称兼容的服务都已验证。没有配置时聊天输入会提示设置，不会偷偷改用云端。

API Key 按模型配置独立保存在本机数据目录的 SQLite 数据库记录中，重启自动恢复，不返回前端或写入卡片导出。当前为明文存储，备份数据目录也会包含密钥，请保护数据目录。首次初始化可使用环境变量 `TAVERN_TEXT_API_KEY` 导入默认配置；主动清除后重启不会重新采用旧密钥。要使用远程文本服务，必须主动开启云端选项，并使用 HTTPS 域名；你发起的对话与画面草稿素材会发送至该服务。

### 多模型与切换

设置页点击“新增模型”，填写配置名称、Chat Completions 基础地址、模型 ID 和对应密钥，点击“保存并使用新模型”。每套配置独立保存温度、输出长度、上下文长度及云端授权。新配置不会继承另一服务的密钥。现有单模型配置与密钥首次升级时自动迁移。

设置页或聊天工作台顶部可切换已保存模型；聊天和画面推断随之使用选中的配置，已有聊天内容保留。正在生成文本或推断画面时禁止切换，避免中途改变接口。切换会同步到同一后端的其他页面，旧页面提交不同模型的设置会被拒绝。失败不会自动转发给另一供应商。

当前支持 Chat Completions 与 SSE 兼容服务，不直接接受 Anthropic Messages 或 Gemini 原生协议地址。文本传输集中在 `apps/server/src/text-adapter.ts`，与角色上下文及画面推断逻辑分离，后续可在此扩展协议适配。

当前上下文采用保守的 UTF-8 字节预算，不宣称精确 token 计数，也未实现完整酒馆提示词语义。

## 连接本地生图

1. 运行工作区原有的 `../QwenImage21/Start-QwenImage.cmd`，等待 ComfyUI 就绪。
2. 在本应用设置中确认 `http://127.0.0.1:8188`，点击“保存并测试工作流”。
3. 核对实际模型许可与用途，只有确认适用授权后再勾选研究/评估用途确认。
4. 在右侧面板编辑画面描述，选择可选 seed，然后提交。
5. 任务完成后，在当前聊天或“灵感画廊”查看、下载图片。

窄屏点击顶部图片按钮打开生图面板。ComfyUI 离线时，已创建任务会持久化等待；服务上线后自动调度。图像模型与工作流模板由服务端固定，浏览器不能传入任意节点图或文件路径。

Qwen-Image-2.1 当前权重为 Qwen Research 许可，研究/评估以外的产品用途应先核对授权。用途确认不构成新的许可。代码实现没有复制酒馆业务源码；本地 API 工作流参考既有部署文件，权重及相关组件仍受其原许可约束。

## 数据、隐私与运行边界

### 保持同一角色

1. 编辑角色，填写“固定身份与体型”和“默认服装”；保存新角色后可添加参考。
2. 上传清晰的面部与全身 PNG，或从本角色图库选一张满意的定妆照。参考应为同一人物、同一种画风。支持非交错 PNG，最大 8MB、4096 像素边长。
3. 开启会话，在右侧确认“角色定稿”和“当前服装”，填写本次动作、场景与构图后生图。有参考时自动使用 Qwen-Image-2.1 参考条件工作流。
4. 需要换装时点击“确认换装”，填写完整服装，可选服装参考。从选中的消息（未选择时为最后一条消息）起生效，之后一直沿用，直到下一次确认换装。修改角色默认服装只影响新会话。

任务会保存不可变的参考与服装快照，后续编辑角色不改变已排队任务。身份参考不会自动替换为上一张生成图。参考图有助于一致性，但不能保证五官、体型和鞋饰细节完全不变；目前未接入 LoRA。角色 JSON 导出只带身份与服装文字，参考图片需要单独保留并在导入后重新绑定。

参考图片保存在本应用媒体目录，并复制到本机 ComfyUI 的 `input/TavernStudio/references/<job-id>/`。本版没有自动清理旧参考，需在备份与磁盘管理时一并考虑。

### 存储

- 数据位置：`apps/server/data/app.sqlite` 与 `apps/server/data/media/`。首次运行自动创建，已加入 `.gitignore`。
- 卡片和聊天只保存在新目录，不写入原酒馆数据；本项目不会修改现有酒馆页面与配置。
- 仅适用于本机单用户。当前是本地会话，不是账号密码登录；不防御同机恶意进程或能读取数据目录的其他系统用户。
- 数据库内的聊天、人物资料和提示词未加密。保护目录权限；不要把数据目录公开或直接同步到不可信服务。
- SQLite 使用独占连接防止多个后端重复调度。需要备份时，先停止应用，再完整复制 `apps/server/data`；在线备份和一键恢复尚未实现。
- 任务结果不明时进入核对状态，不自动重发。“确认并释放”只停止追踪，不能保证旧服务没有生成过图片。
- 图片归档失败会重试归档，不重新调用扩散模型。请先排查磁盘空间、权限和 ComfyUI 原始输出是否仍存在。
- 资源协调仅覆盖本应用发出的请求，不能阻止其他程序或 ComfyUI 网页直接占用 GPU。
- 禁止将后端改为公网/局域网服务后直接投入使用；多用户认证、TLS、权限隔离尚未完成。
